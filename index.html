Personal Google Drive Integration

Information about a private integration using rclone.

Purpose

This Google OAuth application is used by its owner to authorize rclone, an open-source command-line tool, to access the owner's Google Drive. The integration supports personal file access and media-library use on a privately administered server.

Who uses this application?

This is a personal-use integration. It is not offered as a public service, and the owner does not provide accounts or services to other users.

Data access and handling

Google Drive access is used only for the owner's own file-management and media-serving purposes. Files are accessed through rclone and the owner's server configuration. The owner does not intentionally sell or share data obtained through this integration with third parties.

Security

OAuth credentials are stored in the owner's server configuration and should be kept private. This site does not collect Google passwords, OAuth tokens, or files.
